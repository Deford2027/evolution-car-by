# Evolution Car BY — две версии главной страницы

Перенос главной с Tilda (https://evcars-by.tilda.ws/) в код и вторая версия
той же страницы в стилистике https://zeekr.com.ru/. Тексты у обеих версий
одинаковые, различается только подача.

## Что где

Копия сайта с тильды (https://evcars-by.tilda.ws), 130 страниц:

- `/` — главная
- `/china/`, `/korea/`, `/europa/`, `/usa/` — страницы направлений
- `/catalog/` — каталог, 107 позиций из выгрузки Tilda Store
- `/catalog/<раздел>/` — in_stock, made_to_order, from_china, from_korea,
  from_europe, from_usa, electro_car, hybrid
- `/car/<slug>/` — карточка автомобиля, по одной на позицию
- `/about/`, `/contact/`, `/portfolio/`, `/rew/`, `/thank_page/`
- `/policy/`, `/agreement/`, `/legal_data/` — правовые
- `/zeekr/` — альтернативная главная в стилистике zeekr.com.ru

## Стек

- Astro (static) + Preact-острова. Острова общие для обеих версий,
  внешний вид задаётся токенами темы.
- Тексты только в `src/content/` — в компонентах не должно быть
  русских строк, иначе версии разъедутся.

## Структура

- `src/content/site.ts` — бренд, телефон, адреса, меню.
- `src/content/home.ts` — тексты всех секций главной.
- `src/content/cars.ts` — каталог: восемь моделей с характеристиками,
  описаниями, ценами и сроками поставки.
- `src/lib/seo.ts` — canonical, meta и блоки schema.org.
- `src/styles/base.css` — сброс, контейнер, кнопки, карточки.
- `src/styles/theme-v1.css`, `theme-v2.css` — семантические токены тем,
  скоуп `:root[data-theme="v1"|"v2"]`. Hex-значения живут только здесь.
- `src/styles/islands.css` — стили островов, на токенах.
- `src/components/v1/`, `src/components/v2/` — по 14 секций в каждой.
- `src/components/islands/` — `MobileMenu`, `LeadForm`, `Quiz`, `ModalHost`.
- `src/lib/submit.ts` — отправка заявки.
- `public/img/` — картинки, забранные с тильды + Unsplash для отзывов.

## Запуск

```
npm run dev      # astro dev
npm run build    # статика в dist/
```

Проверка вёрстки: собрать и поднять `dist/` статикой, снять скриншоты
на 375/768/1024/1440, убедиться что `scrollWidth === innerWidth`.

## Что не доделано

- **Заявки никуда не уходят.** На Pages нет приёмника: без
  `PUBLIC_LEAD_ENDPOINT` форма пишет заявку в консоль браузера и показывает
  «спасибо». Для MVP-визуала так и задумано; перед запуском нужен сервер
  или внешний сервис приёма.
- **Видео о сервисе** — исходника нет, в модалке стоит заглушка с постером.
- **Своей 404-страницы нет:** `src/pages/404.astro` не создан, на ошибочный
  адрес GitHub Pages отдаёт свою стандартную заглушку.
- **Шрифты** подключены с Google Fonts. Tilda Sans проприетарный, в V1 вместо
  него Golos Text — ближайший по рисунку.
- **Отзывы** используют фотографии Unsplash — так же, как на самой тильде.
- **Фотографии в каталоге демонстрационные** и не соответствуют конкретным
  машинам. На странице модели об этом есть оговорка, но перед запуском нужны
  реальные фото от клиента.
- **Цены и характеристики в `cars.ts`** взяты из Figma-концепта и открытых
  данных по моделям. Перед публикацией их должен подтвердить клиент.
- **robots.txt закрывает сайт целиком** — снять перед релизом вместе
  с `noindex` в BaseLayout.

## Админка (статическая, MVP)

Админка — визуальный MVP на GitHub Pages: <https://ликсианг.рф/admin/>.
Сервера нет: после сборки Astro скрипт `admin/build.py` читает готовые
страницы из `dist` и кладёт рядом статические страницы `dist/admin/`.
Шаг стоит в workflow сразу после `npm run build`.

- `admin/build.py` — сборщик: обход страниц, типы и группы, список деревом
  с поиском в браузере, карточки, заглушки. Запуск: `python3 admin/build.py dist`.
- `admin/page_seo.py` — карточка страницы: тайтл, описание, H1, альт-теги,
  AEO, привязка к городу, кластер запросов. Здесь же выбор миниатюры.
- `admin/ui.py` — стили и каркас страниц админки.

Разделы: «Страницы сайта» (все страницы по сущностям), разбор каждой
страницы, заглушки «Метрика», «SEO-аналитика», «Точка А».

**Словарь сущностей — общий язык с владельцем** (принят 11.10.2026). Каждая
страница — сущность с рабочим именем; в разговоре и в задачах страницы
называются именно так:

- **Главная** — «Главная», «Главная Zeekr».
- **Хаб** — ведёт на другие страницы, полного списка товаров нет:
  «Хаб Китай» (`/china/`), «Хаб Минск» (`/minsk/`) и т.д.
- **Каталог** — список товаров: «Общий каталог» (`/catalog/`), «Каталог Китай»
  (`/catalog/iz-kitaya/`), «Каталог Geely» (`/catalog/geely/`),
  «Каталог Zeekr-версии» (`/zeekr/catalog/`).
- **Карточка товара** — одна машина, имя из H1: «Geely Coolray»,
  «Geely Coolray (Zeekr)».
- **Страница** — о компании, контакты, отзывы, пригнали.
- **Техническая страница** — «Спасибо». **Юридическая страница** — политика,
  соглашение, юридические данные. Технические и юридические — раздельно.

«Хаб Китай» и «Каталог Китай» — разные страницы. В списке каталоги
раскрываются, как в Тильде: внутри их карточки товара. Одна карточка стоит
во всех своих каталогах, но считается один раз. Состав каталога берётся из
опубликованной страницы каталога (ссылки компонента CarCard), а не из
повтора правил подборок.

**Приёма заявок и входа по паролю нет** — для них нужен серверный процесс,
которого у Pages не бывает. Владелец решил (11.10.2026): MVP, нужен только
визуал. Серверная версия — приём заявок в SQLite, вход по паролю, доска
заявок по этапам — лежит в истории git: коммиты 8ee9aa7…ce2ba66. Её можно
вернуть, когда появится свой сервер. Админка открыта без пароля: в ней
только публичное содержимое сайта, персональных данных нет.

Списки разделов каталога, направлений, городов и фиксированных страниц
продублированы в `admin/build.py` и `admin/page_seo.py` — при новом разделе,
городе или странице дополнить их, иначе страница попадёт в «Страницы» с
именем из H1. На сборке с префиксом подпапки (если когда-то вернётся
`rebase-dist`) сборщик остановится с ошибкой — запускать его до префикса.

## Правила

- Файл кода ≤800 строк, один шаг — ≤3 файла, коммит после каждого шага.
- Mobile-first, `clamp()` для размеров, `minmax(0, 1fr)` в сетках.
- Hex-цвета в компонентах не писать — только токены темы.
- **Списки машин — только через общую сетку `.product-grid`** (`src/styles/base.css`):
  каталоги, подборки, марки, хабы, «Пригнали», «похожие» и любые новые.
  На телефоне две карточки в ряд, с 1024 px — три; узкая карточка сама
  компактная (CarCard, container query). Своих сеток для карточек не заводить.
- **Фильтр каталога** — общий `CatalogFilter`: в каждой строке первым стоит
  чип «Все», выбранный признак показывает только подходящие машины.
  Стандарт владельца от 12.10.2026 — действует для всех будущих каталогов.
