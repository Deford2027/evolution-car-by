# Задача для Codex: убрать парковку reg.ru из DNS ликсианг.рф

Статус на 17.10.2026 — **не сделано**, нужна панель reg.ru.

## В чём проблема

У домена `ликсианг.рф` (`xn--80agnajes3a.xn--p1ai`) в записи `@` кроме четырёх
адресов GitHub Pages осталась пятая A-запись — `95.163.244.138`. Это парковка
reg.ru. DNS отдаёт адреса по кругу, поэтому примерно каждый пятый заход
попадает на заглушку: главная отвечает, а внутренние страницы и картинки
отдают 404. Из-за этой же записи GitHub не выпускает сертификат, и сайт
работает только по http.

## Проверка (воспроизводится в любой момент)

```
curl -s -o /dev/null -w '%{http_code}\n' --resolve 'xn--80agnajes3a.xn--p1ai:80:185.199.108.153' \
  http://xn--80agnajes3a.xn--p1ai/catalog/     # 200 — через GitHub
curl -s -o /dev/null -w '%{http_code}\n' --resolve 'xn--80agnajes3a.xn--p1ai:80:95.163.244.138' \
  http://xn--80agnajes3a.xn--p1ai/catalog/     # 404 — через парковку
```

## Что сделать в панели reg.ru

Аккаунт `artemiy.galimov@yandex.ru`, домен ликсианг.рф, раздел «DNS-серверы
и управление зоной» (NS: ns1.reg.ru, ns2.reg.ru).

1. Удалить A-запись `@` → `95.163.244.138`.
2. Проверить, что у `@` остались ровно четыре A-записи:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. Для `www`: удалить A-запись на `95.163.244.138`, оставить
   CNAME `www` → `tema-mail.github.io.` (с точкой на конце).
4. **MX и TXT не трогать** — на домене почта Яндекса.

## После правки

Подождать обновления зоны (до часа), затем в настройках GitHub Pages
репозитория `tema-mail/evolution-car-by` нажать «Enforce HTTPS» — сертификат
выпустится сам. Проверить обе команды выше: обе должны давать 200, а
`https://ликсианг.рф/` — открываться без предупреждения браузера.
